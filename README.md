## Самостоятельные лабораторные

Каждая папка `lab-*` содержит отдельную работу для сдачи: HTML, готовый CSS, исходный SCSS, необходимые скрипты и изображения, а также `report/report.pdf` с исходниками отчёта. Между лабораторными нет ссылок и зависимостей. Папку можно скопировать отдельно от репозитория.

Откройте `lab-01/index.html` в браузере. Страница использует локальный файл `style.css` и работает без установки пакетов. Короткие команды запуска и пересборки CSS находятся в README каждой работы.

Для просмотра через HTTP из корня репозитория:

```sh
python3 -m http.server 8000
```

Адрес страницы: <http://localhost:8000/lab-01/>.

## Сборка отчёта

Нужны XeLaTeX, пакеты из TeX Live, Times New Roman для текста, FreeMono для листингов и Python 3 с Pygments. Если шрифты установлены в системе:

```sh
python3 -m pip install -r lab-01/report/requirements.txt
bash lab-01/report/build.sh
```

Если TTF хранятся отдельно, укажите каталог с файлами `Times.TTF`, `Timesbd.TTF`, `Timesi.TTF` и `Timesbi.TTF`:

```sh
FONT_DIR=/path/to/fonts bash lab-01/report/build.sh
```

Каждая лабораторная оформляется отдельной веткой. Pull request направляется в `main`.

## Сборка стилей

Исходники стилей хранятся в `style.scss`. Для изменения оформления установите зависимости и запустите Sass:

```sh
cd lab-01
npm ci
npm run build:css
```

`style.css` содержит результат минификации. Этот файл подключается к HTML и хранится в репозитории, поэтому готовую страницу можно открыть без Node.js. В отчёте приведены читаемые исходники SCSS с подсветкой синтаксиса.

## Закрытый сайт

Сайт [labs.spbetu.ru](https://labs.spbetu.ru) предоставляет доступ к работам и PDF после входа через UpdSpace ID. Доступ открыт только пользователям из списка разрешённых.

[Первый этап](infra/01-foundation/README.md) описывает бакет, роли, сертификат и Lockbox. [Второй этап](infra/02-release/README.md) проверяет сборку, выпускает приложение и позволяет вернуть предыдущий артефакт. [Схема](infra/ARCHITECTURE.md) объясняет доступ и границы сервисов.

Каталог `site/` содержит каталог работ, стили и скрипт оболочки просмотра. Сборка создаёт страницы `/view/lab-*/` с возвратом к списку, переходами между работами и ссылкой на отчёт. Лабораторная отображается в отдельном iframe на всю ширину окна: её CSS не пересекается со стилями навигации. Прямая ссылка `/lab-*/` открывает работу без оболочки; обе версии требуют входа.

`infra/02-release/build.py` собирает сайт в новый каталог и не изменяет `lab-*`. Только в размещённую копию ЛР7 добавляется получение цитаты из закрытой Cloud Function; при недоступности API остаётся сохранённая цитата. Изображение для хостинга заменяется на WebP без потери пикселей, исходный PNG остаётся в лабораторной.

Для локального просмотра собранного сайта без облачной авторизации:

```sh
python3 infra/02-release/build.py --release-id "$(git rev-parse HEAD)" --output dist/site
python3 -m http.server 8000 --directory dist/site
```

Каталог `dist/site` перед сборкой должен отсутствовать. Авторизацию и закрытый API проверяют отдельно через сервис `services/gate`; локальный файловый сервер их не предоставляет.
