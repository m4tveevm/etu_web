\section{Цель и выполнение работы}
Цель работы: изменить оформление страницы с помощью медиазапросов и построить адаптивную сетку карточек.

В \code{media.html} цвет текста зависит от ширины окна: до 480~px он красный, от 481 до 800~px зелёный, свыше 800~px синий. Условия \code{max-width} включают пороговые значения.

Страница \code{index.html} содержит шесть карточек с иллюстрациями и текстом. Сетка состоит из трёх колонок, при ширине до 800~px из двух, до 480~px из одной. Иллюстрация взята из предоставленного образца. CSS скрывает лишнюю часть снимка, сам файл изображения не изменён.

\caption{Сетка карточек при ширине окна 1426 px}
\end{figure}

\section{Результат}
При изменении ширины окна содержимое и порядок карточек сохраняются. Их высота зависит от объёма текста, изображения загружаются локально. Переключение стилей выполняется средствами CSS без JavaScript.
