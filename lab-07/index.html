Заголовок сайта

На широком экране карточки стоят в три колонки. Каждая содержит иллюстрацию и отдельный абзац. Общая сетка задаёт одинаковую ширину колонок, а промежутки между ними отделяют соседние блоки. Высота ряда определяется самой высокой карточкой. Остальные карточки занимают ту же высоту, поэтому нижние границы остаются на одной линии.

Когда ширина окна уменьшается, места для трёх колонок становится недостаточно. Медиазапрос меняет шаблон сетки. Сначала остаются две колонки, затем карточки располагаются одна под другой. Порядок элементов в HTML сохраняется при любом размере экрана. Изображение подстраивается под доступную ширину и не выходит за границы блока.

Внутренние отступы отделяют текст от рамки. Абзац переносится по ширине карточки, а межстрочный интервал сохраняется при изменении окна. Для узкого экрана уменьшается размер главного заголовка. Пользователь может прочитать всю страницу с помощью вертикальной прокрутки.

Карточки не имеют фиксированной высоты. Если в абзац добавить несколько предложений, блок увеличится вместе с текстом. Такой способ подходит для материалов разного объёма. Рамка охватывает всё содержимое, а следующий ряд начинается после завершения предыдущего.

Изображение повторяется в каждой карточке, как в образце. Его область показа ограничена квадратной рамкой без видимой границы. Масштаб меняется вместе с шириной колонки, поэтому пропорции иллюстрации сохраняются на большом и маленьком экране.

Для проверки адаптивности достаточно изменить ширину окна браузера. На границе медиазапроса число колонок меняется сразу. При этом текст, изображение и рамка остаются внутри страницы. Отдельный пример со сменой цвета показывает работу двух порогов: 480 и 800 пикселей.
