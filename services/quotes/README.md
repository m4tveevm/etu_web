# Сервис цитат

`GET /api/v1/quote` возвращает одну цитату. Выбор выполняет Cloud Function через
`node:crypto.randomInt`. В каталоге три короткие цитаты:

- Кэн Канеки: «Сколько будет тысяча минус семь?» из 12-й серии первого сезона
  «Токийского гуля». Реплика сохранена из ЛР7;
  [источник серии](https://www.crunchyroll.com/watch/GK9U34MXN/ghoul) указан в отчёте.
- Козьма Прутков: «Если хочешь быть счастливым, будь им.» из «Плодов раздумья»,
  раздел «Мысли и афоризмы», № 80. Текст сверён с
  [электронным изданием ImWerden, PDF с. 8](https://imwerden.de/pdf/kozma_prutkov_plodi_rasdumia.pdf#page=8),
  которое воспроизводит полное собрание сочинений 1965 года.
- Александр Пушкин: «Да здравствует солнце, да скроется тьма!» из
  «Вакхической песни» (1825). Текст сверён с
  [публикацией Русской виртуальной библиотеки](https://rvb.ru/pt/pushkin/0382-ru.html).

Ответ имеет обязательные поля `schemaVersion: 1`, `id`, `text`, `language: "ru"`
и `attribution`. В `attribution` обязательны `speaker`, `work`, `sourceUrl`;
`season` и `episode` необязательны и принимают положительные целые числа.
Другие поля запрещены. ID содержит до 80 строчных латинских букв, цифр и дефисов
между группами символов. Длина текста составляет от 1 до 500 символов JavaScript,
имён автора и произведения до 120, HTTPS-ссылки до 2048. Пустые строки,
пробелы по краям, управляющие символы и URL с логином или паролем отклоняются.

`contract.mjs` проверяет ответ и на сервере, и в браузере. Каталог хранится
в `quotes.json`. Новую запись добавляют вместе с проверяемым источником.
Параметры запроса, тело, заголовки и контекст пользователя не используются.
Ответы имеют `Cache-Control: no-store`; другие HTTP-методы получают 405 и
`Allow: GET`. CORS-заголовки функция не устанавливает.

Для Yandex Cloud Functions используются Node.js 22 и entrypoint `index.handler`.
Gate проверяет пользователя и вызывает приватную функцию через свой сервисный аккаунт.
IAM и маршрут описываются в `infra/`, а не в обработчике.

Из этой папки:

```sh
npm test
npm run package
```

Архив `dist/quotes.zip` содержит только `index.js`, `contract.mjs`, `quotes.json`
и `package.json`. Для сборки нужен Python 3; внешних Node.js-зависимостей нет.
Проверка обработчика основана на [формате Yandex Cloud Functions](https://yandex.cloud/en/docs/functions/lang/nodejs/handler).
