Матвеев М. А., группа 4372. Преподаватель: Нечитайленко Р. А.

## Просмотр

Откройте `index.html` в браузере либо из корня репозитория запустите:

```sh
python3 -m http.server 8000
```

Адрес: <http://localhost:8000/lab-05/>.

При ширине окна 1020 px размеры и цвета каркаса повторяют итоговый образец из задания. Белый фон шапки занимает всю ширину окна, высота баннера — 319 px, нижней полосы — 109 px. До 600 px основные и нижние колонки располагаются вертикально.

## Отчёт

[PDF](report/report.pdf), [исходник LaTeX](report/report.tex).

Для сборки нужны XeLaTeX, пакеты TeX Live, Times New Roman, FreeMono и Python 3 с Pygments:

```sh
python3 -m pip install -r lab-05/report/requirements.txt
bash lab-05/report/build.sh
```

Если Times New Roman хранится отдельно, укажите каталог с `Times.TTF`, `Timesbd.TTF`, `Timesi.TTF` и `Timesbi.TTF`:

```sh
FONT_DIR=/path/to/fonts bash lab-05/report/build.sh
```

## Проверка

Снимок Chromium 153 при размере окна 1020×1280 px совпадает с итоговым PNG из задания: различий по пикселям нет. На ширинах 320, 375, 600, 601, 768, 1020 и 1440 px проверены загрузка страницы, отсутствие горизонтальной прокрутки и расположение блоков.

## Сборка стилей

Исходники стилей хранятся в `style.scss`. Для изменения оформления установите зависимости и запустите Sass:

```sh
cd lab-05
npm ci
npm run build:css
```

`style.css` содержит результат минификации. Этот файл подключается к HTML и хранится в репозитории, поэтому готовую страницу можно открыть без Node.js. В отчёте приведены читаемые исходники SCSS с подсветкой синтаксиса.
