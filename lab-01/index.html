Оформление текста

HTML задаёт структуру страницы: заголовки, абзацы и списки. CSS определяет их внешний вид. Общие стили удобно хранить в отдельном файле, чтобы менять оформление всей страницы.

Заголовок второго уровня

Размер шрифта помогает различать заголовки и основной текст. Межстрочный интервал оставляет пространство между строками, а список разделяет короткие рекомендации на отдельные пункты.

  • Объединяйте связанные мысли в один абзац.
  • Используйте заголовки, чтобы обозначить тему раздела.
  • Оформляйте перечисления с помощью списка.
