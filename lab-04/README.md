## Просмотр

Откройте `index.html` в браузере либо из корня репозитория запустите:

```sh
python3 -m http.server 8000
```

Адрес: <http://localhost:8000/lab-04/>.

Форма повторяет поля и расположение элементов образца. Email и сообщение обязательны: их проверяет браузер. Обработчик события submit отменяет отправку, данные остаются в полях. При ширине окна до 420 px поля располагаются в одну колонку.

## Отчёт

[PDF](report/report.pdf), [исходник LaTeX](report/report.tex).

Для сборки нужны XeLaTeX, пакеты TeX Live, Times New Roman, FreeMono и Python 3 с Pygments:

```sh
python3 -m pip install -r lab-04/report/requirements.txt
bash lab-04/report/build.sh
```

Если Times New Roman хранится отдельно, укажите каталог с `Times.TTF`, `Timesbd.TTF`, `Timesi.TTF` и `Timesbi.TTF`:

```sh
FONT_DIR=/path/to/fonts bash lab-04/report/build.sh
```

## Проверка

Для проверки оставьте email и сообщение пустыми и нажмите Submit. Затем введите неверный email, исправьте его и заполните сообщение. Браузер должен отклонить первые два случая. После корректного ввода страница остаётся открытой, а значения полей сохраняются. Флажок подписки можно включить и выключить.

## Сборка стилей

Исходники стилей хранятся в `style.scss`. Для изменения оформления установите зависимости и запустите Sass:

```sh
cd lab-04
npm ci
npm run build:css
```

`style.css` содержит результат минификации. Этот файл подключается к HTML и хранится в репозитории, поэтому готовую страницу можно открыть без Node.js. В отчёте приведены читаемые исходники SCSS с подсветкой синтаксиса.
